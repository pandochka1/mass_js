Задача 1

Сумма и среднее арифметическое

Вычислить сумму всех элементов массива и их среднее арифметическое. Классическая агрегация: в отдельной переменной накапливаем сумму, затем делим на длину.
Как это работает: переменная sum обнуляется, цикл проходит по массиву и прибавляет каждый элемент. Среднее = sum / arr.length. Если массив пуст, среднее даст NaN — поэтому деление имеет смысл только при непустом массиве. 
let arr = [10, 20, 30, 40, 50];
let sum = 0;

for (let i = 0; i < arr.length; i++) {
  sum += arr[i];
}

let avg = sum / arr.length;
console.log("Сумма:", sum);
console.log("Среднее:", avg);
Построчное пояснение
let arr = [10, 20, 30, 40, 50];Создаём массив из пяти чисел. Это исходные данные задачи.
let sum = 0;Заводим переменную-накопитель. Ноль — «нейтральный» элемент для сложения: прибавление 0 не меняет результат, поэтому с него безопасно начинать.
for (let i = 0; i < arr.length; i++) {Цикл идёт по индексам от 0 до последнего. Условие i < arr.length гарантирует, что мы не выйдем за границы массива.
  sum += arr[i];Прибавляем текущий элемент к накопителю. Запись sum += x — то же самое, что sum = sum + x.
}Конец тела цикла. После него управление возвращается к шагу i++, и начинается следующая итерация.
let avg = sum / arr.length;Среднее арифметическое — сумма делённая на количество элементов.
console.log("Сумма:", sum);Выводим сумму в консоль.
console.log("Среднее:", avg);Выводим среднее арифметическое в консоль.
Задача 2

Поиск максимума и минимума

Найти наибольший и наименьший элемент массива без использования Math.max/Math.min.
Как это работает: за максимум принимаем первый элемент, затем сравниваем с каждым следующим. Если встретился больший — обновляем. То же для минимума. Такой приём называется «поиск экстремума» и работает за один проход массива. 
let arr = [12, 45, 3, 78, 24, 9];
let max = arr[0];
let min = arr[0];

for (let i = 1; i < arr.length; i++) {
  if (arr[i] > max) max = arr[i];
  if (arr[i] < min) min = arr[i];
}

console.log("Максимум:", max);
console.log("Минимум:", min);
Построчное пояснение
let arr = [12, 45, 3, 78, 24, 9];Создаём массив чисел.
let max = arr[0];Берём первый элемент как стартовый «лучший кандидат» на максимум. Именно поэтому сравнение ищется не с нуля, а с элемента под индексом 1 — первый уже «зарезервирован».
let min = arr[0];То же для минимума: пока считаем, что первый элемент — наименьший.
for (let i = 1; i < arr.length; i++) {Цикл начинаем с индекса 1, потому что элемент под индексом 0 мы уже учли. Это экономит одну «бессмысленную» итерацию сравнения элемента с самим собой.
  if (arr[i] > max) max = arr[i];Если текущий элемент больше найденного максимума — он становится новым максимумом.
  if (arr[i] < min) min = arr[i];Если текущий элемент меньше найденного минимума — он становится новым минимумом. Обе проверки выполняются независимо на каждой итерации.
}Конец цикла. После полного прохода в max и min — экстремумы всего массива.
console.log("Максимум:", max);Выводим максимум.
console.log("Минимум:", min);Выводим минимум.
Задача 3

Подсчёт чётных и нечётных

Определить, сколько в массиве чётных и нечётных элементов.
Как это работает: два счётчика. Каждый элемент проверяем через остаток от деления на 2: arr[i] % 2 === 0 — чётное. Это пример фильтрации признака по всему массиву. 
let arr = [3, 8, 1, 14, 7, 22];
let even = 0;
let odd = 0;

for (let i = 0; i < arr.length; i++) {
  if (arr[i] % 2 === 0) {
    even++;
  } else {
    odd++;
  }
}

console.log("Чётных:", even);
console.log("Нечётных:", odd);
Построчное пояснение
let arr = [3, 8, 1, 14, 7, 22];Создаём массив чисел.
let even = 0;Счётчик чётных элементов. Начинает с нуля, в цикле будет увеличиваться.
let odd = 0;Счётчик нечётных элементов.
for (let i = 0; i < arr.length; i++) {Перебираем все индексы массива.
  if (arr[i] % 2 === 0) {Вычисляем остаток от деления на 2. Если остаток 0 — число делится на 2 нацело, то есть чётное.
    even++;Если чётное — увеличиваем счётчик чётных на 1. Запись even++ — то же, что even = even + 1.
  } else {Если остаток не 0 — число нечётное.
    odd++;Увеличиваем счётчик нечётных на 1.
  }Конец условия.
}Конец цикла. Каждый элемент попадает ровно в один из счётчиков.
console.log("Чётных:", even);Выводим количество чётных.
console.log("Нечётных:", odd);Выводим количество нечётных.
Задача 4

Поиск первого вхождения

Найти индекс первого элемента, равного заданному значению. Если элемента нет — вернуть -1.
Как это работает: стартовое значение -1 означает «не найдено». Идём по массиву; при совпадении запоминаем индекс и прерываем цикл оператором break, чтобы найти именно первое вхождение. 
let arr = [4, 7, 2, 9, 7, 1];
let target = 7;
let found = -1;

for (let i = 0; i < arr.length; i++) {
  if (arr[i] === target) {
    found = i;
    break;
  }
}

console.log("Индекс элемента:", found);
Построчное пояснение
let arr = [4, 7, 2, 9, 7, 1];Создаём массив. Заметьте: значение 7 встречается дважды — на индексах 1 и 4.
let target = 7;Значение, которое мы ищем.
let found = -1;-1 — «пустое» значение индекса. Оно означает «ещё не нашли». Такой приём удобен тем, что -1 не может быть настоящим индексом массива и легко проверяется.
for (let i = 0; i < arr.length; i++) {Проходим по всем индексам массива.
  if (arr[i] === target) {Строгое сравнение текущего элемента с искомым. === важно: неявное приведение типов здесь не нужно.
    found = i;Запоминаем индекс найденного элемента.
    break;Прерываем цикл. break гарантирует, что мы найдём именно первое вхождение — после него цикл не продолжается, даже если дальше есть ещё такие же значения.
  }Конец условия.
}Конец цикла.
console.log("Индекс элемента:", found);Выводим результат. Если было -1 — значит, значение в массиве не встречается.
Задача 5

Разворот массива

Развернуть массив в обратном порядке без использования встроенного reverse().
Как это работает: меняем местами первый элемент с последним, второй с предпоследним и так до середины. Обратите внимание: цикл идёт только до arr.length / 2, иначе элементы поменяются обратно. 
let arr = [5, 3, 8, 1, 9];

for (let i = 0; i < arr.length / 2; i++) {
  let temp = arr[i];
  arr[i] = arr[arr.length - 1 - i];
  arr[arr.length - 1 - i] = temp;
}

console.log(arr);
Построчное пояснение
let arr = [5, 3, 8, 1, 9];Создаём массив из пяти элементов.
for (let i = 0; i < arr.length / 2; i++) {Цикл идёт только до середины массива (5 / 2 = 2.5 → итерации i = 0, 1, 2). Если бы цикл прошёл весь массив, элементы поменялись бы местами дважды и вернулись бы в исходное положение.
  let temp = arr[i];Сохраняем текущий элемент во временную переменную. Без неё мы бы потеряли значение при перезаписи — это «кладовая» для обмена.
  arr[i] = arr[arr.length - 1 - i];На место «левого» элемента записываем «правый». Индекс правого вычисляется как length - 1 - i: для i=0 это 4 (последний), для i=1 — 3 (предпоследний) и так далее.
  arr[arr.length - 1 - i] = temp;На место «правого» элемента записываем сохранённый «левый». После этого шага пара элементов обменялась позициями.
}Конец цикла. К середине все пары «конец–начало» уже обменялись.
console.log(arr);Выводим развёрнутый массив: [9, 1, 8, 3, 5].
Задача 6

Сортировка пузырьком

Отсортировать массив по возрастанию методом пузырька (bubble sort). Это базовая учебная сортировка: соседние элементы сравниваются попарно и обмениваются местами, если стоят в неправильном порядке.
Как это работает: внешний цикл повторяет проходы, внутренний — сравнивает пары arr[j] и arr[j+1]. За каждый проход наибольший элемент «всплывает» в конец, поэтому внутренний цикл каждый раз становится короче на 1 (условие arr.length - 1 - i). Обмен выполняется через временную переменную temp. 
let arr = [64, 34, 25, 12, 22];
let sorted = arr.slice();

for (let i = 0; i < sorted.length - 1; i++) {
  for (let j = 0; j < sorted.length - 1 - i; j++) {
    if (sorted[j] > sorted[j + 1]) {
      let temp = sorted[j];
      sorted[j] = sorted[j + 1];
      sorted[j + 1] = temp;
    }
  }
}

console.log(sorted);
Построчное пояснение
let arr = [64, 34, 25, 12, 22];Исходный массив. Для наглядности сортируем копию, чтобы исходный не изменился.
let sorted = arr.slice();slice() без аргументов создаёт копию массива. Если бы мы написали let sorted = arr, обе переменные ссылались бы на один массив, и сортировка изменила бы исходный.
for (let i = 0; i < sorted.length - 1; i++) {Внешний цикл — количество «проходов». После каждого прохода самый большой элемент «всплывает» в конец, поэтому достаточно length - 1 проходов.
  for (let j = 0; j < sorted.length - 1 - i; j++) {Внутренний цикл — сравнение соседних пар. Граница length - 1 - i становится короче с каждым проходом, ведь «всплывшие» элементы в конце уже отсортированы и трогать их не нужно.
    if (sorted[j] > sorted[j + 1]) {Если левый сосед больше правого — порядок нарушен.
      let temp = sorted[j];Сохраняем левый элемент. Обмен двух элементов всегда требует временную переменную.
      sorted[j] = sorted[j + 1];Записываем правый элемент на место левого.
      sorted[j + 1] = temp;Записываем сохранённый левый на место правого. Пара теперь в правильном порядке.
    }Конец условия обмена.
  }Конец внутреннего цикла — один полный проход завершён.
}Конец внешнего цикла — все проходы завершены, массив отсортирован.
console.log(sorted);Выводим отсортированный массив по возрастанию.
Кибербезопасность
Сортировка применяется в ИБ для упорядочивания логов по времени, сравнения хеш-таблиц и выявления аномалий. Простая пузырьковая сортировка на больших данных слишком медленная — на практике алгоритмы быстрее (быстрая, сортировка слиянием), но принцип обмена местами сохраняется.
Задача 7

Сдвиг массива влево

Сдвинуть элементы массива влево на указанное количество позиций: первые элементы переходят в конец.
Как это работает: за один шаг сохраняем первый элемент во временную переменную, сдвигаем всё на одну позицию влево, записываем сохранённый элемент в конец. Повторяем нужное число раз. Если k больше длины — берём k % length (лишние полные обороты ничего не меняют). 
let arr = [5, 9, 3, 7, 1];
let k = 2;

for (let s = 0; s < k % arr.length; s++) {
  let first = arr[0];
  for (let i = 0; i < arr.length - 1; i++) {
    arr[i] = arr[i + 1];
  }
  arr[arr.length - 1] = first;
}

console.log(arr);
Построчное пояснение
let arr = [5, 9, 3, 7, 1];Исходный массив.
let k = 2;На сколько позиций сдвигаем влево.
for (let s = 0; s < k % arr.length; s++) {Повторяем сдвиг на 1 позицию нужное число раз. k % arr.length отбрасывает лишние полные обороты: сдвиг на 5 для массива из 5 элементов это то же, что сдвиг на 0 — массив вернулся бы в исходное состояние.
  let first = arr[0];Запоминаем первый элемент — он должен уйти в конец. Без сохранения мы бы его потеряли при сдвиге.
  for (let i = 0; i < arr.length - 1; i++) {Внутренний цикл двигает каждый элемент на одну позицию влево. Доходим до length - 1, потому что последний элемент будет перезаписан из сохранённого first.
    arr[i] = arr[i + 1];На позицию i записываем значение с позиции i+1. Так «кольцо» значений сдвигается влево.
  }Конец внутреннего цикла — все элементы сместились влево на 1.
  arr[arr.length - 1] = first;Записываем сохранённый первый элемент в конец. Один шаг сдвига завершён.
}Конец внешнего цикла — выполнено k шагов сдвига.
console.log(arr);Выводим результат: [3, 7, 1, 5, 9] (сдвиг на 2 позиции влево).
Задача 8

Фильтрация по условию

Создать новый массив, в который попадут только элементы, большие заданного порога.
Как это работает: заводим пустой массив result. В цикле проверяем каждый элемент: если он проходит условие — добавляем через push(). Исходный массив не изменяется. 
let arr = [12, 45, 3, 78, 24, 9];
let threshold = 20;
let result = [];

for (let i = 0; i < arr.length; i++) {
  if (arr[i] > threshold) {
    result.push(arr[i]);
  }
}

console.log(result);
Построчное пояснение
let arr = [12, 45, 3, 78, 24, 9];Исходный массив.
let threshold = 20;Порог: будем отбирать элементы больше этого числа.
let result = [];Новый пустой массив для результата. Обратите внимание: исходный массив останется нетронутым — фильтрация всегда строит новый массив.
for (let i = 0; i < arr.length; i++) {Перебираем все индексы исходного массива.
  if (arr[i] > threshold) {Проверяем, что текущий элемент больше порога — условие фильтрации.
    result.push(arr[i]);Если условие верно — метод push добавляет элемент в конец результирующего массива.
  }Конец условия. Элементы, не прошедшие порог, просто пропускаются.
}Конец цикла.
console.log(result);Выводим отфильтрованный массив: [45, 78, 24].
Задача 9

Количество вхождений значения

Посчитать, сколько раз заданное значение встречается в массиве.
Как это работает: в отличие от поиска первого вхождения (задача 4), здесь нельзя останавливаться при первом совпадении. Счётчик увеличивается на каждой итерации, где элемент равен искомому. Обратите внимание: для случайного массива с диапазоном 1–6 значение 7 встретится 0 раз. 
let arr = [3, 7, 3, 9, 3, 1];
let value = 3;
let count = 0;

for (let i = 0; i < arr.length; i++) {
  if (arr[i] === value) {
    count++;
  }
}

console.log("Вхождений:", count);
Построчное пояснение
let arr = [3, 7, 3, 9, 3, 1];Исходный массив. Значение 3 встречается трижды.
let value = 3;Значение, вхождения которого считаем.
let count = 0;Счётчик вхождений.
for (let i = 0; i < arr.length; i++) {Перебираем все индексы массива.
  if (arr[i] === value) {Строгое сравнение текущего элемента с искомым значением.
    count++;При совпадении увеличиваем счётчик. В отличие от поиска первого вхождения, цикл здесь не прерывается — нужно посчитать все совпадения.
  }Конец условия.
}Конец цикла — прошли весь массив.
console.log("Вхождений:", count);Выводим итоговое количество: 3.
Задача 10

Сортировка выбором

Отсортировать массив по возрастанию методом выбора (selection sort): находим минимальный элемент и ставим его на первое место, затем ищем минимальный среди оставшихся и ставим на второе и т.д.
Как это работает: внешний цикл фиксирует позицию i, внутренний — ищет индекс минимального элемента в хвосте массива (от i до конца). Найденный минимум меняется местами с элементом на позиции i. С каждой итерацией «отсортированная» часть растёт, «неотсортированная» — уменьшается. 
let arr = [64, 34, 25, 12, 22];

for (let i = 0; i < arr.length - 1; i++) {
  let minIndex = i;

  for (let j = i + 1; j < arr.length; j++) {
    if (arr[j] < arr[minIndex]) {
      minIndex = j;
    }
  }

  if (minIndex !== i) {
    let temp = arr[i];
    arr[i] = arr[minIndex];
    arr[minIndex] = temp;
  }
}

console.log(arr);
Построчное пояснение
let arr = [64, 34, 25, 12, 22];Исходный массив.
for (let i = 0; i < arr.length - 1; i++) {Внешний цикл: позиция, которую надо «заполнить». Последний элемент заполнять не нужно — после всех шагов он сам окажется на месте.
  let minIndex = i;Предполагаем, что на текущей позиции уже стоит минимальный элемент из оставшейся части. Запоминаем его индекс как minIndex.
  for (let j = i + 1; j < arr.length; j++) {Внутренний цикл ищет минимум в «хвосте» массива — от позиции i+1 до конца.
    if (arr[j] < arr[minIndex]) {Если нашли элемент меньше текущего минимума.
      minIndex = j;Обновляем индекс минимального элемента.
    }Конец условия.
  }Конец внутреннего цикла — теперь minIndex указывает на самый маленький элемент хвоста.
  if (minIndex !== i) {Если минимум уже стоит на своём месте — обмен не нужен. Проверка экономит лишнюю операцию.
    let temp = arr[i];Начинаем обмен: сохраняем элемент с позиции i во временную переменную.
    arr[i] = arr[minIndex];Ставим минимум на позицию i — теперь слева отсортированная часть растёт.
    arr[minIndex] = temp;Ставим сохранённый элемент на освободившееся место.
  }Конец условия обмена.
}Конец внешнего цикла — массив отсортирован по возрастанию.
console.log(arr);Выводим результат: [12, 22, 25, 34, 64].

Первый и последний
